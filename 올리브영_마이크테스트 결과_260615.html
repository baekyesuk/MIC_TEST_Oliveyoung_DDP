Section 01

지표의 의미와 데이터 범위

STT 질문 행 780건

STT 엑셀에서 사용자 질문이 기록된 한 행을 1건으로 집계합니다. ETC·테스트·연속질문도 포함됩니다.

질문 1회 = STT 질문 행 1건
Session CSV 721개

사용자의 한 번의 이용 시작부터 종료까지를 1개 Session으로 집계합니다. Session 하나에 질문이 여러 건 있을 수 있으며, STT 질문이 없는 Session도 포함됩니다.

STT가 기록된 Session 302개 · 전체 Session 721개
답변 정확도

테스트·ETC·연속질문을 모두 포함합니다. ETC는 특정 인텐트에 분류되지 않았다는 뜻이며, 질문에 맞는 답변이면 정확으로 평가합니다.

정확 679 ÷ 전체 질문 780 = 87.1%
실제 운영 지표

인텐트 비율과 실제 이용 현황에서는 테스트가 포함된 Session 24개를 제외합니다. 답변 정확도와 STT 오인식 추정률에는 테스트도 포함합니다.

721개 − 테스트 Session 24개 = 697개
연속질문 처리

중간 답변 공백을 바로 실패로 보지 않고 같은 Session의 후속 답변과 연결합니다. 연결되지 않은 경우에만 최종 미응답으로 집계합니다.

후속 연결 평가 12건 · 최종 미응답 8건
ETC의 의미

추천·면세·멤버십 등 사전 정의 인텐트에 포함되지 않은 입력입니다. ETC 자체는 노이즈나 STT 오류를 의미하지 않으며, 마이크 감도 판단에는 내용의 실제 비관련성 확인이 추가로 필요합니다.
